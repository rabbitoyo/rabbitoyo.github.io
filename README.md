## 📝 精選專案

### [React 步道檢索 - YeStep │ 每一步，找回生活的呼吸](https://malrichsu.github.io/yestep/)

「從微小的 Step 開始，探索山稜的光影。為你精準檢索每一條森林步道，重新連結自然與自己。」

- 前端技術：`Vite` `SCSS` `Bootstrap5` `React` `React Router` `Lottie` `Swiper` `Axios` `JSON Server`
- 負責功能：
  - 進階篩選與動態排序系統：實作多維度條件篩選（難度、時長、瀑布/雲海等景觀），並結合熱門度即時排序，大幅提升搜尋精準度。
  - 狀態持久化與 URL 分頁機制：運用 React Router 將篩選與分頁狀態同步至 URL 參數，確保使用者在頁面重整或分享連結時，能完整還原搜尋結果。
  - 即時數據交互統計：整合後端 API 實作熱門度自動計數（PATCH 請求），將使用者點擊行為即時反饋於前端展示，強化資訊互動性。
  - 客製化 UI/UX 動畫元件：獨立開發專屬 TrailLoading 組件並整合 Lottie 動畫，以視覺化腳步效果優化數據加載間隙的用戶體驗。
  - 高複用組件化開發：封裝多個高度解耦的 UI 元件，在維持程式碼整潔的同時，提升系統後續維護與擴充的效率。
  - 效能優化與非同步處理：針對 RESTful API 數據獲取實作精準的 Loading State 管理，確保非同步資料傳輸過程中的介面流暢度。

### [React 旅遊電商 - TravNote 旅途](https://rabbitoyo.github.io/travnote/)

「專為旅遊愛好者打造的線上購票平台，從城市街角到自然秘境，提供精選的旅遊套票與體驗行程。」

- 前端技術：`Vite` `SCSS` `Bootstrap5` `React` `React Router` `React Hook Form` `Redux Toolkit` `Lottie` `Swiper` `Axios`
- 負責功能：
  - 首頁展示：精選熱門旅遊套票推薦，支援 Swiper 輪播展示
  - 旅程探索：瀏覽各地景點與行程，規劃專屬旅程
  - 活動資訊：掌握最新旅遊活動與限定體驗
  - 商品購物：完整的商品瀏覽、詳情查看、加入購物車功能
  - 購物車系統：靈活的購物車管理，支援數量調整與商品刪除
  - 訂單流程：完整的訂單建立、確認與成功頁面
  - 旅者故事：社群分享的真實旅遊靈感
  - 管理後台：管理員登入與儀表板功能
